# план: тактильность открытки

**цель:** связать движения с пересчётом, выбором оформления и сохранением открытки.

**архитектура:** существующие html/css/es modules. небольшой модуль предпросмотра обновляет svg и управляет прерываемыми web animations. scene.js остаётся источником статического экспорта. никаких новых зависимостей.

- [x] добавить браузерные регрессии в `tests/motion-browser.mjs`, подключить в `tests/browser.mjs`; увидеть отсутствие сохранения svg-узлов и защиты занятого экспорта.
- [x] добавить ключи строк в `src/scene.js`, обновление svg и общий механизм отмены движения в `src/motion.js`; подключить смысловые события в `src/app.js`.
- [x] в `styles.css` задать общие длительности, состояния кнопок, полей, вкладок, строк и импорта; в `index.html` добавить тихую отметку сохранения рядом со статусом. сохранить области нажатия.
- [x] завершить состояния импорта и экспорта, защитить быстрые повторные действия, проверить ошибки без изменения предыдущей открытки.
- [x] выполнить `npm test` и `npm run test:browser`, просмотреть desktop/mobile и движение в браузере; проверить статический экспорт во время перехода, reduced motion и отсутствие web animations api.
- [x] записать результаты и ограничения, проверить `git diff --check` и итоговый diff.

**результаты:** исходно 41 модульный тест и 57 браузерных проверок. итоговый общий прогон с параллельно добавленным сохранением проектов: 49 модульных тестов и 142 браузерные проверки проходят. проверены курсор и фокус, обновление и сортировка без замены svg, быстрые переключения, вложенные drag-события, успешный и ошибочный png, защита занятой кнопки от перерисовок, все 20 заполненных строк, длинный текст, оба формата, 320/390/768/1440 px, touch, reduced motion и работа без web animations api. png во время движения побайтно совпадает с итоговым; svg и автономный html содержат полную статическую сцену. html открыт без сети. общий прогон также проверяет импорт, черновик и файлы проектов.

**визуальная проверка:** редактор и сортировка просмотрены в браузере, мобильные вкладки — при 390 px. скриншоты `test-results/motion-wide.png` и `test-results/motion-mobile.png` просмотрены. независимое ревью не нашло существенных замечаний; дополнительная проверка подтвердила непрерывную геометрию полосы, отсутствие стартовой анимации и очистку после 20 быстрых обновлений.

**границы:** автоматические проверки выполнены в chromium; отдельного прогона firefox и safari не было. сборка и линтер в проекте не настроены. новых зависимостей нет. параллельные изменения проекта сохранены; коммиты, push и публикация не выполнялись.
