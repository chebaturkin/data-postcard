# стол подготовки открытки — план реализации

основание: утверждённые audit.html и redesign.svg в локальном design-audit от 14 октября. существующая ветка codex/useful-postcards, текущие изменения сохраняются.

## 1. построение открытки
- регрессионные тесты: непустые текстовые события не исчезают при скрытии пропусков; диагностические состояния определяются отдельно от картинки; подписи и значения не пересекаются.
- переработать src/scene.js: полный заголовок, итог внизу, единицы один раз, читаемая адаптивная плотность, календарь занятого диапазона/реестр редких дат, группировка дат линии, содержательное описание.
- локальные шрифты с кириллицей, общая геометрия предпросмотра и экспорта; доступная тёмная палитра, убрать декоративные линии.
- проверить unit-тесты и геометрию SVG.

## 2. редактор
- index.html/styles.css/src/app.js: компактная шапка, общая строка источника и сохранение черновика; слева открытка, справа данные/текст/график; палитра и формат рядом с результатом.
- на 390/768 сначала редактор и компактный предпросмотр, отдельный доступный просмотр с возвратом фокуса; на 1440 два столбца.
- исправить фильтрацию пропусков, запрет экспорта диагностики, локализовать ошибки, отделить предупреждения, сохранить сырые правки, добавить отмену замены/сброса.
- сохранить импорты, все виды, палитры, форматы, ручное применение, переносимый JSON, экспорты и reduced-motion.
- 44px цели, фокус, клавиатура, таблица с закреплённой первой колонкой; согласовать 404 и автономный html.

## 3. проверка
- npm test и npm run test:browser, регрессии важных исправлений.
- независимая проверка соответствия аудиту, затем проверка качества кода, исправить замечания.
- визуально проверить 390/768/1440: данные, текст, график, календарь, сторис, ошибки, просмотр, экспорт. сохранить снимки, обновить README.

## результат проверки

реализация завершена в существующей ветке codex/useful-postcards. предыдущие изменения сохранены. проверка соответствия аудиту и отдельная проверка качества пройдены; замечания исправлены.

- npm test: 58/58.
- npm run screenshots: 170 браузерных проверок, включая 390/768/1440, клавиатуру, touch, reduced-motion, импорты, файлы черновика, raw draft, undo и png/svg/html.
- node tests/scene-layout-browser.mjs: 8 сценариев, включая широкие символы, экстремальные числа, 20 строк, редкие события и совпадающие даты.
- визуальная проверка через браузер: 390, 768, 1440; крупный просмотр и экспорт. снимки docs/images/editor.png, mobile.png, tablet.png обновлены.
- git diff --check: без ошибок.

если текст не оставляет места для графика, экспорт блокируется с предложением сократить текст или выбрать сторис. очень плотная открытка сопровождается предупреждением и доступным просмотром 100%. публикация и отправка в репозиторий не выполнялись.
