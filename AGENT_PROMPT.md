# Промпт для агента: Data Postcard

Сделай локальный инструмент, который превращает небольшой CSV/JSON в одну выразительную визуальную открытку. Вход: drag-and-drop CSV/JSON или ручные 5–20 строк. Определи колонки категорий, чисел и дат, покажи понятные ошибки. Дай 4 типа представления: полосы, точки, календарная сетка и временной маршрут. Пользователь редактирует заголовок, подпись, единицы, порядок и тему. Экспорт: PNG, SVG и standalone HTML размером 1200x900 или Stories.

Ценность — данные становятся личным артефактом, а не отчётом. Никакого AI, chart API, сервера, аккаунтов и попытки поддержать весь Excel. Исходные данные не покидают браузер.

Вайб: маленький независимый журнал и полевой дневник. Темы: ночной атлас, бумажная статистика, спортплощадка, архив. У каждой ограниченная палитра из 3–5 цветов, фактура делается линиями и точками, не градиентом. Используй характерную display serif-пару и спокойный humanist sans/mono для чисел. Сначала большая открытка, потом компактные настройки. Никаких SaaS-dashboard, баблов, стекла, pill-кнопок, мета-лейблов и giant CTA. Проверь пустые значения, дубликаты, неверные числа, чёрно-белую печать и офлайн-экспорт. README содержит три набора данных и изображения результата.


## Общие правила

- Сделай рабочий MVP как статический сайт для GitHub Pages.
- Не используй API-ключи, платные сервисы, обязательный backend, серверную базу данных, авторизацию или внешнюю AI-модель.
- Пользовательские файлы обрабатывай только в браузере; данные не отправляй на свой сервер.
- Если внешний URL упирается в CORS или лимиты, оставь полноценный локальный сценарий через ZIP, JSON или CSV.
- Сначала зафиксируй дизайн-систему и пользовательский сценарий, затем пиши код.
- Запрещены градиенты, glassmorphism, декоративные баблы, pill-кнопки, бесконечные карточки, bento-сетки, огромный hero-блок, CTA ради CTA и типичный AI/SaaS-дашборд.
- Не используй Inter, Roboto, Open Sans и похожие шаблонные пары как главный визуальный голос. Выбирай собственные шрифты с хорошей кириллицей и локальными fallback.
- Проверь desktop/mobile, клавиатуру, focus, reduced motion, пустые состояния и понятные ошибки.
