# data postcard

маленький локальный инструмент: берёт CSV или JSON и собирает из него одну выразительную открытку. файл остаётся в браузере — без сервера, аккаунта, API и внешней загрузки.

![пример открытки](./examples/reading-result.svg)

## запустить локально

нужен любой статический сервер. из корня проекта:

```bash
python3 -m http.server 8000
```

откройте <http://localhost:8000>.

## собрать открытку

- перетащите CSV или JSON, выберите файл или вставьте 5–20 строк;
- используйте колонки с категориями, числами и датами — инструмент подскажет, если что-то не сходится;
- выберите режим: полосы, точки, календарная сетка или временной маршрут;
- настройте заголовок, короткую заметку, единицы, порядок, тему и формат;
- сохраните результат как PNG, SVG или автономную HTML-страницу.

пустые значения остаются видимыми, а строки без даты не исчезают из временного маршрута: открытка показывает их в пояснении. ошибочный импорт не заменяет уже собранный результат.

## данные и приватность

файл читается прямо в браузере. он не отправляется на сервер и не требует аккаунта. приложение принимает только CSV и JSON размером до 1 МБ и ограничивает набор 5–20 строками.

## github pages

в репозитории уже есть workflow для GitHub Pages: `.github/workflows/pages.yml`. после включения GitHub Pages с источником `GitHub Actions` каждое обновление ветки `master` публикует корень проекта. `404.html` оставляет ту же тихую навигацию, если кто-то открыл старую ссылку.

## проверить изменения

```bash
npm test
```

тесты проверяют парсер, сортировку, ошибки импорта, доступные тексты, генерацию SVG и безопасные сценарии экспорта.
