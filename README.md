# data postcard

редактор небольших графиков для постов, отчётов и личных итогов. внесите цифры в таблицу, добавьте заголовок и пояснение, выберите оформление — и скачайте готовую открытку.

**[открыть редактор →](https://chebaturkin.github.io/data-postcard/)**

![редактор data postcard: готовая открытка слева, редактируемая таблица справа](docs/images/editor.png)

## для чего он пригодится

когда нужно показать несколько чисел вместе с контекстом: куда ушли деньги за месяц, сколько материалов вышло на каждой площадке, как менялась температура или сколько времени нашлось для чтения. открытку можно добавить в пост, отправить в переписке или вставить в отчёт.

внутри есть пять примеров. они помогают попробовать инструмент и понять, как будут выглядеть ваши данные. цифры в примерах демонстрационные.

## собрать свою открытку

1. выберите пример и замените цифры и названия в таблице. строки можно добавлять и удалять. нажмите «обновить открытку».
2. во вкладке «текст» добавьте заголовок, короткое пояснение и единицы измерения.
3. в «оформлении» выберите график, палитру и формат. итог можно показать как сумму или среднее, либо скрыть.
4. скачайте png для публикации, svg для вёрстки или html, который открывается отдельной страницей.

если данные уже собраны, раскройте «загрузить файл или вставить таблицу». можно перетащить csv или json, вставить текст или скопировать ячейки из excel и google sheets. первая строка должна содержать названия колонок. csv может использовать запятые или точку с запятой, а ячейки из таблицы — табуляцию.

```csv
категория,сумма
продукты,18400
кафе,6200
транспорт,3800
```

полосы и точки помогают сравнить значения. линия показывает изменения по датам, календарь — записи по дням. для линии и календаря нужна колонка с датами, например `2026-10-14`.

## данные и черновик

данные обрабатываются в браузере и не отправляются на сервер. аккаунт не нужен. черновик с последними применёнными данными, текстом и оформлением сохраняется в этом браузере и восстанавливается после перезагрузки. изменения в таблице сохраняются после кнопки «обновить открытку»; текст и оформление — сразу.

кнопка «начать заново» возвращает пример чтения. черновик привязан к браузеру и адресу сайта; очистка данных сайта удалит его. если браузер запрещает сохранение, редактор продолжит работать и сообщит об этом.

инструмент рассчитан на **2–20 строк** и файлы csv/json до **1 мб**. пустые значения можно оставить видимыми. если в таблице или файле есть ошибка, предыдущая открытка сохраняется. большие таблицы лучше предварительно сократить до нужных категорий или периода.

два размера: **1200 × 900** для поста и **1080 × 1920** для сторис. png, svg и автономный html используют тот же график, что и предпросмотр. html также содержит применённые данные, поэтому перед пересылкой стоит проверить содержимое таблицы.

## запустить локально

приложение — статический сайт на html, css и javascript. сборка и установка зависимостей для запуска не нужны. подойдёт любой статический сервер, например:

```bash
python3 -m http.server 8000
```

откройте [локальный редактор](http://localhost:8000).

## проверить изменения

для тестов парсера, таблицы, черновика, сортировки, графиков и экспорта нужен node.js:

```bash
npm test
```

для браузерной проверки:

```bash
npm install
npx playwright install chromium
npm run test:browser
```

браузерный тест сам запускает статический сервер. он проверяет редактирование, импорт, ошибки, вкладки с клавиатуры, сохранение черновика, палитры, виды графиков, размеры скачанных png и отсутствие переполнения на экранах от 320 до 1440 пикселей.

обновить скриншоты в readme:

```bash
npm run screenshots
```
